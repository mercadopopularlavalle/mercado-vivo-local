# Mercado Popular

Crea una app web de clasificados y compraventa local llamada Mercado Popular, estilo Mercadolibre pero sencilla y moderna. Necesito una pantalla principal con barra de búsqueda, filtros por categorías ( Hogar, Indumentaria, Comidas y Bebidas, Servicios, Eléctrónica y Vehículos) y una cuadrícula de tarjetas con foto, título, precio y ubicación. Al hacer click en un producto se abre el detalle con descripción completa y un botón grande que diga " Contactar por Whattsapp" que redirija a wa.me con el teléfono del vendedor. Incluye un botón "Publicar venta" y una sección "Mis publicaciones" para los usuarios donde pueda pausar o eliminar avisos
